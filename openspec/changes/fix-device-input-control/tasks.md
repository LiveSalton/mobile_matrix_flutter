- [x] 2.12 按 Web STF 映射发送 keyDown/keyUp/keyPress，并将输入法切换键转发为 `KEYCODE_SWITCH_CHARSET`。
- [x] 2.13 在左侧设备信息栏增加“复制截屏”按钮，通过 ADB 获取 PNG 并直接复制到电脑图片剪贴板；移除录制视频及放弃录制流程，不生成桌面文件。
